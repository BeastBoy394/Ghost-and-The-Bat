A fun, fast-paced browser mini-game built using p5.js and JavaScript. Test your reflexes and see how high you can score before time runs out!
🔗 Play the Game Live Here!
🎮 How to Play
Objective: Catch as many yellow ghosts as you can before the 30-second timer runs out!
Scoring:
🟡 Yellow Ghost: Click it to earn +1 point (it will teleport to a new random location).
🟢 Green Bat: Avoid it! Clicking the bat will subtract -1 point.
Controls: Use your mouse cursor to click the characters.
🛠️ Built With
p5.js (JavaScript Library for creative coding)
HTML5 & CSS3
GitHub Pages (for hosting)
